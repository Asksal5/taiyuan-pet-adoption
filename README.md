# 太原市流浪动物领养中心 — 网站原型

## 启动
直接用浏览器打开 `index.html` 即可。也可在当前文件夹运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

## 页面功能
- 自适应桌面和移动端的首页
- 猫咪/狗狗分类、关键词搜索、动物详情弹窗
- 领养申请、志愿者报名与留言咨询演示表单
- 领养流程、公告、关于我们和联系方式板块
- 表单演示数据存入当前浏览器 localStorage，不会发送到服务器

## 上线前必须完成
1. 替换所有虚构宠物资料和演示公告，确认图片使用权。
2. 核实机构正式名称、经营/公益性质、地址、电话和实际领养条件。
3. 接入后端、管理端、真实申请提交流程和权限机制。
4. 完成隐私政策、个人信息保护、安全措施与必要的备案。
5. 本页面使用 Unsplash 远程图片，需要联网浏览；可将授权图片下载并部署在自己的静态资源目录。

## 参考说明
以 http://www.szadoptpet.com/ 的公益领养主题和可检索到的栏目内容作为功能参考。参考网站首页未能抓取，因而不是像素级复制。
